# 2026-11-23 — Turn a one-off edit into a reusable skill

On Nov 21 I captured the retro-poster kinetic-type style as a reusable skill instead of a one-off edit: a recipe plus taste guidelines plus a 27-beat asset map in one folder, with the reference frames extracted first and new plates generated only in the same measured palette.

The next day the same skill edited a completely different clip — Sam Altman’s “13 rules” interview — in the same style, without re-explaining anything. Lesson: when a style works, write it down once as a recipe with its real assets and rules, and it becomes a tool you can hand to any coding agent instead of a trick only one edit remembers.
