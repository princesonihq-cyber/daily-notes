# 2026-11-20 — Sitemap and canonical must match the live domain

Fixed a real indexing snag on princearon.us.ci this week: the sitemap was still listing princearon.vercel.app URLs, so Search Console threw 7 "URL not allowed" errors for the princearon.us.ci property. Rewriting the sitemap to only the live domain cleared all seven.

Same lesson for canonicals: the site canonical pointed at the old Vercel subdomain, which 404s. Moving it to princearon.us.ci (in HTML, SEO head, and site config) means Google now sees one true home for every page instead of two competing ones.
